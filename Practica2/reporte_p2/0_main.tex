%%%%% Resumen %%%%%
\begin{abstract}
Fue medida el cociente carga-masa usando un diodo 1v2 al vacío y usando la Ley de Child-Langmuir, el valor obtenido fue  $\frac{e}{m_e} = 1.983e11 \pm 3.842e12 \frac{c}{Kg}$, y teniendo un error porcentual de $E_r = -0.113$. También se midió la relación entre el voltaje y la corriente que establece esta ley, dando un resultado menor al esperado con error porcentual $E_r = -0.149$.
\vspace{2mm}
